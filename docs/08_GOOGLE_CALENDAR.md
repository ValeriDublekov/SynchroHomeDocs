# Архитектурен План: Интеграция с Google Calendar
## Документ: 08_GOOGLE_CALENDAR.md

Този документ описва архитектурата за показване и двупосочна/еднопосочна синхронизация на напомнянията в **Google Calendar**.

---

### 1. Архитектурни Варианти за Интеграция

| Характеристика | Вариант 1: Direct Google Calendar API v3 (Препоръчан) | Вариант 2: Частен iCal / ICS Feed (`webcal://`) |
|---|---|---|
| **Реакция при промяна** | **Мигновена (Real-Time)**: При натискане на "Готово", събитието в календара веднага се обновява или пренасрочва. | **Забавена (8–24 часа)**: Google Calendar кешира външни iCal линкове и ги обновява бавно. |
| **Сложност на настройката** | Изисква Google OAuth 2.0 Client ID + Secret в Google Cloud Console. | Много лесна: генерира се криптиран уникален URL токен. |
| **Възможност за промяна** | Пълен запис: актуализиране на заглавие (`[✓ Изпълнено]`), цвят и време. | Само за четене (Read-only). |
| **Отделен календар** | Може да създаде автоматично посветен вторичен календар `"RemindCore"`. | Добавя се като отделен абонаментен календар. |

---

### 2. Препоръчана Реализация: Google Calendar API v3

#### 2.1. Поток на Автентикация (OAuth 2.0 Offline Access)
1. В Web интерфейса на RemindCore потребителят натиска **"Свържи с Google Calendar"**.
2. Браузърът пренасочва към Google OAuth съгласие със scope:
   `https://www.googleapis.com/auth/calendar.events`
3. Backend-ът получава Authorization Code и го разменя за `access_token` и `refresh_token`.
4. `refresh_token` се криптира с AES-256 (GCM) и се записва в таблица `google_calendar_sync_states`.

---

#### 2.2. Жизнен цикъл на календарно събитие

```
[ Създаване на Напомняне ]
           │
           v
  .NET API извиква Google Calendar API:
  Events.Insert(calendarId, new Event {
      Summary = "Профилактика на пералня",
      Start = 2026-11-01T10:30:00+02:00,
      End   = 2026-11-01T11:00:00+02:00,
      Reminders = { UseDefault = false } // Да не се дублират аларми
  })
           │
           v
  Записва полученото google_calendar_event_id в reminder_instances!

                 │
[ Потребителят натиска "Готово" на телефона на 8 Ноември ]
                 │
                 v
  1. Старото събитие се маркира като изпълнено:
     Summary = "✓ [Изпълнено] Профилактика на пералня"
     ColorId = "10" (Зелен цвят в Google Calendar)
  2. Генерира се НОВО събитие в календара за следващата дата:
     Start = 2027-01-08T10:30:00+02:00 (при плаващ график)
```

---

#### 2.3. Алтернативен лек вариант: Автономен iCal Feed
Ако потребителят не желае да конфигурира Google Cloud OAuth конзола:
- Backend-ът предоставя защитен URL:
  `GET /api/calendar/feed/{user_token}.ics`
- Този URL генерира стандартен RFC 5545 iCalendar файл в реално време, съдържащ всички предстоящи инстанции.
- Потребителят просто добавя линка в Google Calendar чрез *"Add calendar -> From URL"*.
